# Battle Tree Canvas

競技ポケモン向けの **ツリー式 対戦シミュレート用メモアプリ**（Pokémon Champions Regulation M-A／シングル・ダブル対応）。

対戦分岐をターンごとのツリーとして整理し、各分岐に **自分/相手の行動・ダメージ計算結果・HP変化・盤面状態・勝ち筋/負け筋ラベル・崩壊ポイント・メモ** を記録できます。

> このプロダクトでは **AIによる分析・最善手提案・自動レビュー・自動勝率計算は一切行いません。**
> ユーザー自身が考えた対戦分岐を、見やすく記録・比較・共有するためのキャンバスです。

## 主な機能（MVP）

- **プロジェクト作成** — 検討単位ごとに作成。シングル / ダブルを選択
- **構築入力** — 自分・相手の6体（ポケモン名・持ち物・特性・性格・技・実数値/努力値・各種メモ・メガ候補フラグ・メガ運用分類）
- **構築テキストインポート** — ポケソル形式の構築テキストを貼り付けて6体を一括取り込み（種族/性別/フォーム/持ち物/特性/性格/実数値・努力値/技を解析、メガストーン所持は自動でメガ候補化。テラスタイプ行は無視）
- **世界線ツリー** — ターンノードを親子関係でつなぐ分岐ツリー。追加・複製・削除
- **ノード色分け** — 緑 / 黄 / 赤 / 青 / 紫 / 灰
- **勝ち筋ラベル** — 主線 / 副線 / 非常線 / 負け筋 / 確認分岐 / 崩壊ポイント / 保留
- **盤面表示** — HP%バー・状態異常・天候・フィールド・追い風・トリル・壁・設置
- **ダメージメモ** — 外部ダメ計の結果を手入力（攻撃側→防御側・技・最小/最大/想定%・備考）
- **ルート評価** — メガ依存度・非メガ自立性・第2軸・メガ不選出時の勝ち筋・崩壊理由
- **ルート比較・レビュー** — 末端ルートを横並びで一覧。勝ち筋ラベル/リスク色/メガ依存度/非メガ自立性の集計、崩壊ポイント/負け筋一覧
- **構築記事用 Markdown エクスポート** — 構築・ツリー・ルート比較・集計を Markdown 化（コピー / .md ダウンロード）
- **ローカル保存** — ブラウザの localStorage に自動保存
- **JSON エクスポート / インポート**
- **共有URL** — プロジェクト内容をURLに埋め込み、読み取り専用ビューで共有（複製可）

### Phase 4：ダメージ計算補助（AIは使わない・純粋な文字列処理）

- **ダメ計コピペ解析** — 外部ダメージ計算ツールの出力を貼り付け→ %範囲・確定数・技名・攻防ポケモンを自動抽出。名前は構築ロスターと照合してプルダウンを自動設定（ポケモン徹底攻略系の日本語表記・Pokémon Showdown calc の英語表記の両方に対応）
- **HP%半自動反映** — ダメージメモから盤面の防御側HPへ最小/最大ダメージをワンクリック反映
- **確定数メモ / 先制技圏内 / スカーフ圏内** — ダメージメモごとの専用フィールド

### レギュレーション対応（M-A / M-B 切り替え）

レギュレーション定義は [`lib/regulations.ts`](lib/regulations.ts) に集約。プロジェクト作成時に選択でき、環境移行時は概要タブから既存プロジェクトの切り替えも可能。新レギュレーション（M-B など）の確定情報が出たら、原則このファイルのみ更新すれば反映される設計。

## 技術スタック

- [Next.js 15](https://nextjs.org/)（App Router, 静的書き出し `output: export`）
- TypeScript
- Tailwind CSS v4
- 状態は完全クライアントサイド（バックエンドなし / localStorage 保存）

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
```

### 本番ビルド（静的書き出し）

```bash
npm run build    # out/ に静的ファイルを生成
```

`out/` を任意の静的ホスティング（Vercel / GitHub Pages / Netlify など）へ配置できます。

GitHub Pages のようにサブパスで配信する場合は、ビルド時に環境変数を設定します。

```bash
NEXT_PUBLIC_BASE_PATH=/Battle-Tree-Canvas npm run build
```

```
  tree.ts             ツリー操作（純粋関数）

  share.ts            共有URLエンコード/デコード
  io.ts               JSON / Markdown エクスポート, JSON インポート
```

## 方針（やらないこと）

AI分析 / AI最善手提案 / AI構築診断 / 自動勝率計算 / 完全自動ダメージ計算 は **行いません**。
本アプリは「ユーザーが考えた対戦分岐をツリー状に整理する、ポケモン対戦専用の高機能メモアプリ」です。
